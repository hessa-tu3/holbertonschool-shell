# I/O Redirections and Filters

- 0-hello_world: Prints Hello, World followed by a newline.

- 13-unique: Prints words appearing exactly once in sorted order.

- 15-countthatword: Counts lines containing "bin" in /etc/passwd.

- 17-hidethisword: Displays lines in /etc/passwd that do not contain "bin".

- 18-letteronly: Displays lines in sshd_config that start with a letter.

- 19-AZ: Replaces A with Z and c with e from standard input.

- 20-hiago: Removes c and C from standard input.
